# mimiclm

A desktop application built with [Wails](https://wails.io) (Go backend, React + TypeScript frontend).

## Live Development

Run `wails dev` in the project directory. This runs a Vite development server with fast hot-reload for frontend changes. A dev server is also available at http://localhost:34115 for browser-based development with access to the Go methods.

## Building

To build a redistributable production package, run `wails build`.
